# lunabot
bot for [moonlit lilacs](https://discord.gg/lunalilac)

## info
This is just for showcase/eductional purposes. The bot is not meant to be run in other servers.

## contributing
No new features

## privacy controls

`/privacy` explains stored data. `/privacy presence enabled:false` turns off
custom-status vanity role processing, and `/privacy message-stats enabled:false`
stops future message statistics records. `/privacy clear` removes a user's AFK
reason and message statistics and disables future statistics collection.
`/privacy request-deletion` sends other data requests to server staff.

Message statistics and AFK reasons are cleaned up daily after 30 days.
